Assignment 2: Display Student Grades
Q] Write a C program to input first-semester marks for subjects (Maths, Physics, Chemistry, English, CS) of B.Tech. students,
calculate their average, assign grades based on criteria, and display the average marks and grade.

Our ideation for the given question: 
While surfing on the internet we found a website of the Indian Army in which different eligibility criterias for various posts in the Indian Army were mentioned. 
We then decided to create a program to check the user’s eligibility to join in as a Soldier(General Duty)(All Arms) in the Indian army.

In this program you can see an extensive use of if-else and nested if-else statements.

We took the data from the following website:
https://164.100.158.23/eligibility-criteria.htm
